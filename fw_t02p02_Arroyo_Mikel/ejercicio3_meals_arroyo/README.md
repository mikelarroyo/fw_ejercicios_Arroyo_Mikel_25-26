# Angular Meals App — Mikel Arroyo

Práctica de Angular 19+ con consumo de la API [TheMealDB](https://www.themealdb.com/). Permite buscar recetas por categoría, guardarlas, valorarlas, crear recetas propias y planificar la semana.

## URLs

- **Repositorio:** [github.com/mikelarroyogomez/angular-meals-app](https://github.com/mikelarroyogomez/angular-meals-app)
- **Despliegue Netlify:** [angular-meals-arroyo.netlify.app](https://angular-meals-arroyo.netlify.app)

## Tecnologías

- Angular 19+ (standalone components, signals, reactive forms)
- Bootstrap 5
- TheMealDB API
- LocalStorage

## Funcionalidades

- Listado de recetas por categoría
- Guardar / eliminar recetas
- Valorar recetas guardadas
- Crear recetas propias con ingredientes e imágenes
- Planificación semanal
- Autenticación (registro / login) con LocalStorage
- Imágenes optimizadas con `NgOptimizedImage`
- Lazy loading con `@defer`

## Desarrollo local

```bash
npm install
ng serve
```
